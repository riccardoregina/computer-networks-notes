# Computer Networks Notes

A comprehensive collection of study notes on computer networking, structured around the top-down approach. These notes are primarily based on *Computer Networking: A Top-Down Approach* (Kurose et al., 2017) and extensively cite official IETF Request for Comments (RFCs) for technical protocol specifications.

## Table of Contents

1. **Chapter 1: Introduction**
* Basic networking concepts and terminology
* The layered architecture approach (ISO/OSI and TCP/IP reference models)


2. **Chapter 2: Application Layer**
* Principles of network applications and core application-layer protocols


3. **Chapter 3: Transport Layer**
* Connectionless and connection-oriented transport, multiplexing, and reliable data transfer


4. **Chapter 4: Network Layer**
* Routing, forwarding mechanisms, and addressing


5. **Chapter 5: Network Access Layer**
* Data Link layer (error detection, multiple access, switching) and Physical layer concepts


## Current State and Roadmap

**Work in Progress:** These notes are currently undergoing a major expansion.

At present, the content extensively covers the historical and foundational protocols (pre-2000) that form the backbone of the internet. However, network security is an increasingly critical aspect of modern networking, and the repository is being updated to reflect this.
We will dive into modern security principles, threat models, cryptography, and secure variants of standard protocols (e.g., TLS, IPsec, secure DNS) applied across the different layers of the network stack.
